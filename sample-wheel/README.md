# README

## Basics

Uses rotary encoder to track motion of custom 3d printed turntable-style treadmill.  Designed with this encoder:

https://www.sparkfun.com/rotary-encoder-1024-p-r-quadrature.html

`Rotary mount v2 v1 Drawing v1.pdf` is a design for mount to hold rotary encoder that mounts on to the end of any post such as standard Thorlabs posts.  Arduino code interprets data from the encoder and sends it to a python script to record and manage data.
